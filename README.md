# 声间 · Voice Workshop

Windows 本地配音工作台，复用 GPT-SoVITS 与 RVC 官方引擎。支持文字配音、录音换声和无需手工台词的音色训练。

## 下载安装

在本仓库的 **Releases** 下载 `VoiceWorkshop-Setup.exe`，打开后使用已填写的仓库地址，
选择安装目录，点击「下载并安装」。安装器会下载基础模型和独立运行环境，支持断点续传及 SHA-256 校验。
不需要自己安装 Node.js 或 Python，也不依赖发布者的电脑在线。
工作台程序从 GitHub 下载；大型模型和引擎包直接从官方 Hugging Face 下载，不在本仓库重复托管。

当前是 Windows 10/11 x64 + NVIDIA RTX 50 系预览版。完整资源约 17 GB，安装时预留 100 GB；
需要有效 NVIDIA 驱动和 Edge 或 Chrome。安装后从桌面「声间配音」启动，可离线使用。
其他显卡尚未完整测试。

不附带社区角色音色。用户可以导入 GPT-SoVITS 的 `.pth` + `.ckpt`、RVC 的 `.pth`（及可选 `.index`），
或在「训练音色」页面上传自己的清晰录音。文字配音的已配置音色支持直接输入台词；新导入音色可能需要配置一次参考声音。

源码为 MIT；引擎与模型遵循各自许可证，见 [第三方说明](THIRD_PARTY_NOTICES.md)。
发布者操作指南见 [发布指南](docs/发布指南.md)。

## 打开

桌面版：双击桌面的 **声间配音** 图标。它会自动启动本地后端，并以独立窗口打开工作台，支持文字配音、录音换声及音色训练。关闭窗口不会中断后台训练；关机后下次双击会重新启动服务。

桌面 EXE 位于 `dist/desktop/VoiceWorkshop.exe`，运行时使用已有的模型、Python 环境和数据。请保留本项目目录；这是本机安装版，不是可以单独拷走的离线安装包。界面窗口需要电脑上安装的 Edge 或 Chrome。

重新创建桌面版：在 PowerShell 7 中运行 `./scripts/install-desktop.ps1`。脚本复制本机 Node 运行程序、编译 Windows 启动器并创建桌面快捷方式。启动问题记录在 `data/logs/desktop-launcher.log` 和 `data/logs/desktop-server.log`。桌面浏览器数据保存在 `data/desktop-browser`。

双击 `start.cmd`，浏览器访问 http://127.0.0.1:3270 。保持启动窗口打开。

生成按钮依赖引擎安装状态；网页能打开并不代表模型已经安装成功。

## 开发

界面和本地服务没有额外 npm 依赖。安装运行环境后，在项目根目录执行 `node server.mjs`，
运行检查使用 `node --test tests/*.test.mjs`。每个引擎保留独立 Python 环境，
`config.local.json` 保存相对于安装目录的路径，不提交到 Git。

只下载源码不会自动带来模型和 Python 环境。推荐先用 Release 安装器安装，
再在安装目录中修改源码。重新构建安装器和资源包见发布指南。

## 使用

### 文字配音

选择已配置的 GPT-SoVITS 音色 → 填写台词 → 生成。默认参考材料由系统保存、自动调用，不需要每次上传或填写原文。

尚未配置的音色可在「高级设置」中选择一次参考音频，点击「保存为这个音色的默认参考」。参考录音原文可留空；填写时应与录音一致。选择「参考音频克隆」时仍需要提供声音样本。

台词语言和参考音频语言分别设置。建议从一句话测试起，听到结果后再处理长文。

### 录音换声

切换到录音换声 → 上传录音 → 选择 RVC 音色 → 生成。先保持音高偏移为零，再按试听结果调整。

### 社区音色

打开右上角音色库，选择引擎类型。

- RVC：导入 `.pth` 与匹配的可选 `.index`。
- GPT-SoVITS：导入配套 `.ckpt` 和 `.pth` 完整权重，并选择其实际版本。
- 第一版支持 v1、v2、v2Pro、v2ProPlus；尚未接入 LoRA 和 v3/v4 音色。
- 模型文件同后缀不代表互相兼容。导入只登记文件，实际生成时由引擎校验。只导入可信来源的权重。

生成文件在 `data/outputs`；错误的详细日志在 `data/logs`。同一时刻只运行一个 GPU 任务。每次重新启动会把上次中断的任务标记为失败，可重新提交。

### 音色训练

从右上角进入「训练音色」，提供至少 30 秒清晰人声，无需手工填写台词。
系统自动切分、转写并训练 GPT-SoVITS v2，完成后加入音色库，也可以下载 `.pth` 和 `.ckpt`。
建议用 1–10 分钟同一说话人的干净素材；训练不是简单的音频格式转换。

## 当前实现

- 原生网页 + Node.js 本地服务，没有前端构建步骤和额外 npm 依赖。
- 官方引擎代码保存在 engines；适配层只负责传递参数、保存输出。
- 单任务独立进程，结束后释放显存。首次加载与每次启动引擎需要时间。
- 历史任务保存在本地，台词草稿保存在浏览器。
- 当前不是公网多用户服务，也不自动下载全社区角色库。

架构、目录和验收说明见 `docs/技术方案.md`。
