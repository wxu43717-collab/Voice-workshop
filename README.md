# 声间 · Voice Workshop

个人本地配音工作台。复用 GPT-SoVITS 与 RVC 官方引擎，界面以留白、排版、细分隔线组织。

## 打开

桌面版：双击桌面的 **声间配音** 图标。它会自动启动本地后端，并以独立窗口打开工作台，支持文字配音、录音换声及音色训练。关闭窗口不会中断后台训练；关机后下次双击会重新启动服务。

桌面 EXE 位于 `dist/desktop/VoiceWorkshop.exe`，运行时使用已有的模型、Python 环境和数据。请保留本项目目录；这是本机安装版，不是可以单独拷走的离线安装包。界面窗口需要电脑上安装的 Edge 或 Chrome。

重新创建桌面版：在 PowerShell 7 中运行 `./scripts/install-desktop.ps1`。脚本复制本机 Node 运行程序、编译 Windows 启动器并创建桌面快捷方式。启动问题记录在 `data/logs/desktop-launcher.log` 和 `data/logs/desktop-server.log`。桌面浏览器数据保存在 `data/desktop-browser`。

双击 `start.cmd`，浏览器访问 http://127.0.0.1:3270 。保持启动窗口打开。

生成按钮依赖引擎安装状态；网页能打开并不代表模型已经安装成功。

## 安装

本次选用适配 NVIDIA RTX 50 系显卡的官方 Windows 完整包，每个引擎保留独立 Python 环境。

1. `node scripts/download-engines.mjs`：下载整合包并校验 SHA-256。
2. `node scripts/install-engines.mjs`：解压，并对两个 Python 环境分别执行 CUDA 运算检查。
3. `node server.mjs` 或双击 `start.cmd`：启动工作台。

下载元数据已保存在 downloads 中。校验记录为压缩包旁的 `.verified.json`。不要直接删除正在下载的分段文件。

当前两套整合包均已下载、校验并安装。GPT-SoVITS 与 RVC 的独立 Python 环境都通过了 RTX 5060 Laptop GPU 的 CUDA 矩阵测试。

## 使用

### 文字配音

选择「高松灯」等已配置的 GPT-SoVITS 音色 → 填写台词 → 生成。默认参考材料由系统保存、自动调用，不需要每次上传或填写原文。

高松灯 v2 使用官方引擎支持的无参考原文模式，默认参考音频在后台绑定。其他尚未配置的音色可在「高级设置」中选择一次参考音频，点击「保存为这个音色的默认参考」。参考录音原文可留空；填写时应与录音一致。选择「参考音频克隆」时仍需要提供声音样本。

台词语言和参考音频语言分别设置。建议从一句话测试起，听到结果后再处理长文。

### 录音换声

切换到录音换声 → 上传录音 → 选择 RVC 音色 → 生成。先保持音高偏移为零，再按试听结果调整。

### 社区音色

打开右上角音色库，选择引擎类型。

- RVC：导入 `.pth` 与匹配的可选 `.index`。
- GPT-SoVITS：导入配套 `.ckpt` 和 `.pth` 完整权重，并选择其实际版本。
- 第一版支持 v1、v2、v2Pro、v2ProPlus；尚未接入 LoRA 和 v3/v4 音色。
- 模型文件同后缀不代表互相兼容。导入只登记文件，实际生成时由引擎校验。只导入可信来源的权重。

生成文件在 `data/outputs`；错误的详细日志在 `data/logs`。同一时刻只运行一个 GPU 任务。每次重新启动会把上次中断的任务标记为失败，可重新提交。

已完成端到端冒烟验证：GPT-SoVITS 生成 32kHz、单声道、5.4 秒 WAV；RVC 使用 Yui 社区 `.pth + .index` 生成 40kHz、单声道、6.36 秒 WAV。两条记录都可在“最近作品”中试听或下载。

## 当前实现

- 原生网页 + Node.js 本地服务，没有前端构建步骤和额外 npm 依赖。
- 官方引擎代码保存在 engines；适配层只负责传递参数、保存输出。
- 单任务独立进程，结束后释放显存。首次加载与每次启动引擎需要时间。
- 历史任务保存在本地，台词草稿保存在浏览器。
- 当前不是公网多用户服务，也不自动下载全社区角色库。

架构、目录和验收说明见 `docs/技术方案.md`。
