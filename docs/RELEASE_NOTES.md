# 声间 v0.1.0 Preview

本地文字配音、录音换声和音色训练工作台。

## 下载与安装

1. 下载下面附件中的 **VoiceWorkshop-Setup.exe**。
2. 打开安装器，选择安装位置（仓库地址已经填写）。
3. 按需选择录音换声和音色训练，点击「下载并安装」。
4. 安装完成后，从桌面「声间配音」打开工作台。

无需手动安装 Node.js 或 Python。工作台程序从本 GitHub Release 下载；
大模型、引擎和转写文件直接从官方 Hugging Face 仓库下载，不在此 Release 重复托管。
中断后可以继续。
完整下载约 17 GB，建议预留 100 GB 磁盘空间。安装完成后可离线运行。

支持 Windows 10/11 x64；当前引擎包面向 NVIDIA RTX 50 系，需要有效的显卡驱动。
需要安装 Edge 或 Chrome 来显示独立工作台窗口。AMD / Intel GPU 与纯 CPU 尚不支持。

本版本不包含社区角色音色及任何用户录音；安装后可导入社区模型或自己训练。
自动训练无需手工提供台词，效果取决于音频质量和素材量。

预发布软件。EXE 尚未代码签名。源码采用 MIT，第三方组件各自的许可证继续有效。
