# 声间 / Voice Atelier

本轮采用宋体展示标题、黑白灰与少量朱红强调色，桌面为 62 / 38 分栏，手机按创作内容、声音设置、生成、试听顺序排列。所有模型推理、上传、导入与任务排队继续使用原有实现。

## 文件

- web/app.js：原有输入、音色导入、任务提交与状态轮询。
- web/studio.js：版面编排、波形播放器、记录操作。
- web/studio.css：在基础样式之上的视觉与响应式规则。

波形通过浏览器解码实际音频得到。点击或拖动波形定位，左右方向键移动一秒，Home / End 跳到起止位置，空格播放或暂停。读取失败会显示说明，不展示虚构波形。系统减少动态效果设置会禁用入场与循环动画。

删除记录仅保存 deletedAt 标记，在回收站可恢复，原始音频文件不删除。正在生成与排队的记录暂不允许删除。相应接口是 DELETE /api/jobs/:id 和 POST /api/jobs/:id/restore。

## 验证

运行 node --test tests/server.test.mjs 检查接口。

scripts/ui-check.mjs 是本地浏览器集成检查，要求后端运行在 3270 端口、已安装 Chrome 和 Playwright，并存在标题以“你好，欢迎”开头的已完成测试音频。可通过 PLAYWRIGHT_MODULE 指定已有 Playwright 模块路径，无须在生产服务中安装它。

检查会临时将该测试记录移入回收站再恢复，验证真实解码、播放、定位、模式切换、音色库及多种屏幕宽度，并将截图保存到未纳入 Git 的 data/ui-review。
