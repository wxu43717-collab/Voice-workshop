# 声间：本地双引擎配音工作台

## 架构决定

复用官方项目的推理实现与 RTX 50 系 Windows 整合环境。不上来重新安装一套 Python 依赖，不重新实现模型算法，也不把两套不兼容的环境合并。

统一网页 → 本地 Node 服务 → 单任务队列 → 官方引擎 Python 子进程 → WAV 文件。

第一版采用每任务一个推理进程，任务结束释放 GPU。优点是避免 8GB 显存同时驻留两套引擎，隔离依赖；代价是每次生成有模型加载耗时。后续实测后再加入单引擎常驻、切换卸载。

## 引擎与固定版本

|用途|下载包|来源|
|---|---|---|
|文字配音、参考音频克隆|GPT-SoVITS-v2pro-20250604-nvidia50.7z|https://huggingface.co/lj1995/GPT-SoVITS-windows-package|
|录音换声|RVC20260718Nvidia50x0.7z|https://huggingface.co/lj1995/VoiceConversionWebUI|

下载 SHA-256 与文件大小记录在 downloads 中。源码另存为 gpt-sovits-source 和 rvc-source，便于查接口、追踪上游；实际运行优先使用整合包内相匹配的代码和 Python 环境。

## 第一版功能边界

- 文字配音：GPT-SoVITS，参考音频、参考文本、语言、语速。
- 录音换声：RVC，上传录音、音色、半音偏移；默认 RMVPE。
- 音色导入：RVC 的 .pth 与可选 .index；GPT-SoVITS 的 .ckpt 和 .pth 完整权重。显式选择引擎及版本，不根据 .pth 后缀猜测。
- 当前 UI 接入 GPT-SoVITS v1、v2、v2Pro、v2ProPlus 完整权重；LoRA、v3/v4 的适配与资源不属于本轮最小版本。
- 音色导入仅登记文件，首次生成由实际引擎验证兼容性。
- 任务队列、历史记录、音频试听、下载、错误日志。
- 暂不把识别文字、人声分离、训练、实时麦克风变声与多人剧本做进统一 UI；整合包中的原生功能保留。

## 界面

暖白背景、黑灰排版、克制的蓝色操作强调；以留白和细线分区。没有传统 navbar 和卡片网格。主工作区左侧写台词或放录音，右侧只保留本次生成需要的设置。社区音色从独立弹层管理，历史作品用横向列表展示。

## 本地边界

服务只监听 127.0.0.1，拒绝跨来源写入。音频不上传第三方；推理进程禁用 Hugging Face 在线拉取，缺少依赖时明确失败。社区权重按可信来源管理，开源项目许可与各社区模型许可分别保留。此版本是个人本地工具，不是直接开放给陌生用户上传模型的公网站点。

## 验收

1. 两个压缩包大小与 SHA-256 与官方元数据一致。
2. 解压后两个独立 Python 都能在 RTX 5060 上执行 CUDA 运算。
3. GPT-SoVITS 使用参考录音生成新台词，得到非空有效 WAV。
4. RVC 加载社区权重和索引，对录音生成有效 WAV。
5. 在统一工作台完成导入、排队、试听和下载；接口测试及浏览器视检通过。

## 已验证结果（2026-09-26）

- 两个官方 Windows 整合包的 SHA-256 校验通过并完成解压。
- GPT-SoVITS 环境：PyTorch 2.7.0+cu128，识别 `NVIDIA GeForce RTX 5060 Laptop GPU`；RVC 环境：PyTorch 2.7.1+cu128，同样通过 CUDA 矩阵计算。
- GPT-SoVITS 端到端任务成功，输出 32kHz 单声道、5.4 秒 WAV。
- RVC 导入并加载 Yui 社区 `.pth` 与匹配 `.index` 成功，端到端任务输出 40kHz 单声道、6.36 秒 WAV。
- Node 服务安全回归测试 7/7 通过；本地接口已验证导入、排队、生成、输出和错误日志链路。

直接打开 `http://127.0.0.1:3210` 即可检查并使用已生成的最近作品；两条任务记录已经写入“最近作品”。
