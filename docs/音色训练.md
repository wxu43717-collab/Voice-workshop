# 独立音色训练

访问 `/train`，或从配音工作台右上角进入“训练音色”。上传同一人的录音，填写名称、选择录音语言即可；不要求提供或校对文字。当前输出用于 GPT-SoVITS v2 文字配音，不是 RVC 权重。

支持最多 20 个 WAV、MP3、FLAC、M4A、OGG 或 WEBM 文件，合计不超过 600MB、30 分钟。至少 30 秒录音，建议 1–10 分钟清晰、少混响的单人声音。有效、可识别人声不足 20 秒时会停止并提示补充素材。

后台流程：FFmpeg 转为单声道 → 合并短停顿并切片 → 本地 Whisper small 自动转写 → 官方 GPT-SoVITS 特征提取 → SoVITS 与 GPT 微调 → 生成配套 `.pth`、`.ckpt` 和默认参考录音 → 自动加入音色库，并提供 ZIP 与单文件下载。

训练使用现有整合包的 Python 和基础权重。`training-entry.py` 为隔离运行时补充官方项目模块路径，不改写原引擎。默认单卡、batch size 1、SoVITS 8 轮、GPT 12 轮；页面不暴露脚本路径或任意训练参数。

训练与配音共用串行队列。最多 3 个未完成训练任务，最长运行 4 小时。取消正在运行的训练时，Windows 终止对应训练进程树，等进程退出后才释放队列。取消不会删除原始音频。服务重启后，未完成任务标记失败，需重新提交；当前没有断点续训入口。

每个任务使用独立 UUID，素材和训练中间结果位于 `data/training/<id>`，日志位于 `data/logs/<id>.log`。只有训练正常结束且配套权重齐全才写入 `models/gpt-sovits/<id>/voice.json`。不会覆盖已有音色。中间检查点会占用额外磁盘空间，目前保留供排错，不自动清理。

## 检查

- `node --test tests/server.test.mjs tests/training.test.mjs`：接口与任务管理，包括取消、不完整输出不能入库、下载范围限制。
- `scripts/training-ui-check.mjs`：浏览器检查独立页面、无文本字段、移动端、提交结构、取消和导出按钮；提交与任务状态使用模拟传输，不启动训练。使用已有 Playwright，可通过 `PLAYWRIGHT_MODULE` 指定模块位置。
- `scripts/training-smoke.py`：使用现有合成测试录音重复构造短素材，执行真实的 1 轮 SoVITS 和 1 轮 GPT 训练。输出在 `data/training-smoke`，不会加入正式音色库。该检查只验证训练和导出流程，不代表自然录音的音色相似度或正式训练效果。
- `scripts/training-inference-check.py`：将短训练实际导出的权重交给现有配音适配器，生成一句新文本的音频，检查文件能够被加载并完成推理。
