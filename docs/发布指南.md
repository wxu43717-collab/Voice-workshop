# GitHub 发布

源码仓库：https://github.com/wxu43717-collab/Voice-workshop

## 下载方案

GitHub 只托管源码、安装器和工作台程序。大模型与引擎由安装器直接从官方
Hugging Face 仓库下载，不需要上传任何模型分卷，也不需要发布者的电脑在线。

- GPT-SoVITS：https://huggingface.co/lj1995/GPT-SoVITS-windows-package
- RVC：https://huggingface.co/lj1995/VoiceConversionWebUI
- 离线转写：https://huggingface.co/Systran/faster-whisper-small

具体文件的官方直链、大小和 SHA-256 已写入 `release-manifest.json` 并编入 EXE。
它们只在首次安装时下载；安装完成后可离线运行。

## 发布步骤

1. 提交并推送源码到 GitHub 的 `main`。
2. 在 Releases 创建标签 **v0.1.0-preview**，勾选预发布。
3. 标题填写 **声间 v0.1.0 Preview · Windows NVIDIA**，描述使用 `RELEASE_NOTES.md`。
4. 只上传下面五个文件（合计约 38 MB）：
   - `VoiceWorkshop-Setup.exe`
   - `voice-workshop-app.zip`
   - `voice-workshop-source.zip`
   - `release-manifest.json`
   - `SHA256SUMS.txt`
5. 附件齐全后公开发布。也可用 `scripts/publish-release.py` 自动完成上传、校验和发布。

不要上传 `.7z`、模型文件、引擎环境、角色音色、音频、日志或个人配置。
公开源码可以从 `voice-workshop-source.zip` 解压取得，该包不含私人运行数据。

## 分享链接

不要混用不同构建的 EXE、工作台 ZIP 和清单。

## 运行条件

- Windows 10/11 x64，NVIDIA 驱动和 Edge 或 Chrome。
- 当前引擎包面向 RTX 50 系，在 RTX 5060 Laptop 8 GB 上验证；其他显卡尚未完整测试。
- 完整安装仍需下载约 17 GB，建议预留 100 GB；仅文字配音预留 60 GB。
- 支持断点续传、重试和 SHA-256 校验；请使用空文件夹，或继续此前由安装器创建的目录。
- 不附送社区角色音色；用户可自行导入或训练。
- EXE 尚未代码签名。源码采用 MIT；第三方组件遵循各自的许可证。

## 重建

先运行 `scripts/install-desktop.ps1`，再以 Python 3.10+ 运行 `scripts/build-release.py`。
本机构建需要 Node.js 24.13.0、`tools/7zr.exe` 和已校验的上游资源缓存，用于生成固定
文件大小和校验值。大资源只用来生成下载清单，不会放进 GitHub 发布包。
更改版本时同步更新构建与发布脚本中的版本号。
