# GitHub 首次发布

## 1. 发布源码

在 GitHub 创建公开仓库，例如 `voice-workshop`。解压 `voice-workshop-source.zip`，
将里面的文件和目录上传到仓库根目录；不要只把 ZIP 放进源码仓库。
源码采用 MIT 许可证，第三方引擎、模型和依赖保留其自身许可。

该源码包是经过允许清单筛选的公开版本，不含本机音频、角色音色、个人路径配置、
下载缓存、Git 历史、运行日志。不要上传整个本地项目目录。

## 2. 创建下载版本

进入仓库的 Releases → Draft a new release：

- 标签填写 **v0.1.0-preview**，勾选预发布。
- 标题填写 **声间 v0.1.0 Preview · Windows NVIDIA**。
- 描述复制同目录 `RELEASE_NOTES.md` 的内容。
- 上传 `dist/release` 中的全部 `.exe`、`.zip`、分卷 `.001` 至 `.005`、
  `release-manifest.json` 和 `SHA256SUMS.txt`。不要上传 `.tmp`。
- 分卷文件保持原名，每个文件小于 2 GiB；总下载量约 17 GB。
- 等所有附件上传完成后再点击 Publish release。

普通 GitHub 源码上传界面不适合这些大文件；它们必须放到 Release 附件。

## 3. 分享下载链接

把下面的 `账号` 和 `仓库` 换成实际值：

- EXE 直链：`https://github.com/账号/仓库/releases/download/v0.1.0-preview/VoiceWorkshop-Setup.exe`
- 版本页面：`https://github.com/账号/仓库/releases/tag/v0.1.0-preview`

用户下载 EXE，打开后在第一栏粘贴仓库地址或上面的版本页面地址。
无需填写每个模型的下载链接。安装器根据内嵌清单拼出同一 Release 下的所有直链。
仅填写仓库首页时，安装器固定访问 v0.1.0-preview，而不是可能不兼容的 latest。

## 安装与使用边界

- Windows 10/11 x64，已有 NVIDIA 驱动及 Edge 或 Chrome。
- 当前整合包面向 NVIDIA RTX 50 系；已在 RTX 5060 Laptop 8 GB 上验证原项目。
  其他 GPU 尚未逐一测试；不承诺 AMD、Intel GPU 或纯 CPU 支持。
- 完整安装预留 100 GB，只有文字配音预留 60 GB。包含下载缓存、分卷合并和解压空间。
- 用户选择空文件夹；安装器不覆盖普通现有项目，支持继续同一安装目录。
- 下载支持断点续传、重试和 SHA-256 校验。首次下载需要 GitHub 可访问。
- 安装成功后不需要发布者电脑在线，本地生成和训练不依赖 GitHub。
- 关闭工作台窗口不停止后台训练。关机、重启或结束进程会中断任务。
- 不附送社区角色音色。首次使用可导入音色或进入训练页面制作自己的声音。
- EXE 尚未进行商业代码签名，发布者可以另行签名；不要把未签名解释为已获得系统信誉认证。

## 重建

运行 `scripts/install-desktop.ps1` 生成桌面运行文件，再用 Python 3.10+ 运行
`scripts/build-release.py`。需要先准备上游原始压缩包、`tools/7zr.exe`、离线 Whisper
模型和 Node.js 24.13.0。构建程序会校验原始压缩包并生成新的安装器和资源清单。
同一版本的 EXE 和附件必须配套，不要混用不同构建的资源；更改版本时同时修改构建版本。

安装包中只有官方基础模型及原始引擎；上游许可说明见 `THIRD_PARTY_NOTICES.md`。
